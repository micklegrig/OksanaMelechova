# Адвокатське бюро Оксани Мелехової

Сайт адвоката Оксани Мелехової (Київ). Статичний сайт без збірки: HTML, CSS і JavaScript.

## Запуск

Відкрийте `index.html` у браузері або запустіть будь-який статичний сервер у корені репозиторію:

```
python3 -m http.server 8000
```

і перейдіть на http://localhost:8000.

## Структура

- `index.html` — точка входу
- `js/data.js` — контент: послуги, новини, корисні посилання, контакти
- `js/app.js` — сторінки та компоненти (маршрутизація через `#hash`)
- `css/site.css`, `css/home.css` — стилі
- `img/` — фото, карти та іконки
